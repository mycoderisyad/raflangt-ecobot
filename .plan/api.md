# EcoBot API Reference

OpenAPI is generated by FastAPI at `/openapi.json`; interactive documentation is at `/docs`.

## Public endpoints

| Method | Path | Description |
|---|---|---|
| GET | `/` | Application name and process status |
| GET | `/health` | Liveness check |
| POST | `/webhook/telegram` | Telegram update endpoint in webhook mode; requires the Telegram secret header |

## Authentication

| Method | Path | Description |
|---|---|---|
| POST | `/api/v1/auth/login` | Exchange admin username/password for a 60-minute bearer JWT |
| GET | `/api/v1/auth/me` | Return the current admin identity |

Send the token as `Authorization: Bearer <token>` on all other `/api/v1` routes.

## Admin resources

| Resource | Collection routes | Item routes |
|---|---|---|
| Dashboard and analytics | `GET /api/v1/dashboard`, `GET /api/v1/analytics` | — |
| Users | `GET, POST /api/v1/users` | `GET, PATCH, DELETE /api/v1/users/{user_id}` |
| Collection points | `GET, POST /api/v1/locations` | `GET, PATCH, DELETE /api/v1/locations/{id}` |
| Schedules | `GET, POST /api/v1/schedules` | `GET, PATCH, DELETE /api/v1/schedules/{id}` |
| Telegram broadcast | `GET /api/v1/broadcast/audience`, `POST /api/v1/broadcast` | — |
| Email report | `POST /api/v1/reports/send` | — |
| Safe application settings | `GET /api/v1/settings` | — |

Create endpoints return `201`; deletes return `204`; validation errors return `422`. User deletion returns `409` when foreign key history exists. Set `is_active=false` to retain that history.

`user_id` is the Telegram private chat ID exposed over the API. PostgreSQL continues storing the value in the legacy `users.phone_number` column so existing foreign keys and data remain intact. Only numeric private chat IDs are contacted by broadcasts and reminders.
